## A2. 世界観と前提

- プレイヤーは**追放された貴族**。「数枚のシリングと食卓の残り物」以外すべてを奪われ、名誉を取り戻すために異国の地へ渡る。
- 舞台は**ダニエル王の領土**。王が遠征中のため、現在は**アン女王**が統治を任されている。
- 中世の厳しさが背景にある。「肥沃な土地は少なく、食料は減り続け、奇妙な生き物たちがあなたを夕食にしようと狙っている」
- 勝利条件は軍事的ではなく社会的 — **「この地でもっとも崇敬される者」**になること。尺度は**崇敬点（vp）**。
- 中心となる遊び: 地図の周囲にある**6つのギルド**を握り、地図上の**22の拠点**を支配するか、そこに仕える。
- **feudum** はルールブック自身が注釈している。「中世ラテン語を忘れているなら — feudum とはフューダム、つまり封建領主から授けられた土地のことだ！」

## A4. 原文の文体と、日本語版の文体方針

原文は**厳密な手続き文**と**中世風のおどけた語り**を意図的に混ぜている。日本語版でもこの2層を明確に分けないと、ルールが曖昧になる。

| 層 | 該当箇所 | 原文の特徴 | **日本語版の方針** |
| --- | --- | --- | --- |
| **フレーバー／語り** | 導入（p. 1）、各章の導入文、巻末の物語（pp. 22–23）、豆知識 | 疑似古語（"Blimey!"、"thy"）、頭韻の多用、駄洒落（feudal…futile）、動物の鳴き声、感嘆符 | 常体（〜だ・である）で語り口調にし、ルール文と視覚的に区別する。頭韻や駄洒落は無理に音を合わせず、**軽妙さを優先**して意訳する |
| **ルール文** | 上記以外のすべて | 二人称命令形（"you may" / "you must"）、プレイヤーを男性代名詞で総称（"his personal supply"）、太字強調、重要語のALL CAPS（NOT, NEVER, ALWAYS, MUST, FIRST）、見出し付き注記（**Note:** / **Important:** / **Tip:** / **For example,**） | **敬体（〜します・〜できます）**で統一。二人称は原則省略し、必要なら「あなた」。総称の男性代名詞は**訳出しない**（「そのプレイヤー」等に置換）。ALL CAPSは**太字**で表現し、大文字表記自体は再現しない |
| **上級ルール** | 巻物型の枠内 | 引用符付きの能力名（"Distant Kin" など） | 「」付きの日本語能力名＋初出時に英語名を併記。枠内であることを引用ブロック等で示す |
| **豆知識** | 余白 | 史実の脚注（archery butts、krud、硫黄とワイン、feudumの語源） | 常体。ルールと無関係であることが分かる体裁にする |

## A5. 構造モデル: 時代 → ラウンド → ステップ → 手番 → アクション

```
ゲーム全体 GAME  = 5つの時代（I II III IV V）／通常7〜10ラウンド
 時代 EPOCH = 1つ以上のラウンド
  ラウンド ROUND = 5つのステップ（この順序で固定）
    ステップ1 アクションの実行  Take Actions       → 各自4枚（または5枚）のアクションカードを1枚ずつ時計回りに
    ステップ2 ポーンの扶養      Nourish Pawns      → 盤上のポーン1つにつき食料またはワイン1つ（全員同時）
    ステップ3 進行ダイスを振る  Roll Progress Die  → 出た地域の地域タイル1枚を取り除く
    ステップ4 時代マーカーの進行と時代の得点計算  Advance Epoch Marker & Score Epoch — 時代が発生した場合のみ
    ステップ5 ラウンド終了／ゲーム終了と最終得点計算  End Round / End Game & Final Scoring
   手番 TURN = 1人のプレイヤーがアクションカード1枚をプレイすること（連続アクション使用時は2枚）
    アクション ACTION = カード上部の通常アクション（regular action）、または下部の上級特殊能力（special ability）
```

翻訳時に取り違えてはならない関係:

- **時代は地域タイルが取り除かれることで発生する**（ステップ3と改善アクション）。つまりゲームの進行時計は固定ラウンド数ではなく**プレイヤーの活動**が回している。
- **「各時代の夜明けに」**（*at the dawn of each epoch*）は、得点計算と補充が起こる瞬間を指す定型句。**「各時代の始まりに」で統一**する。
- **時代Vが発生するとゲームは終了**する。そのラウンドを終わらせ、時代の得点計算を行い、最終得点計算へ進む。
- 概要文には別の言い方もある。「地域タイルの山が1つ空になるとゲームは終了する」

## A6. ギルドの環と物資の流れ

6つのギルドはボードの周囲に固定の環状で並ぶ。**押し出し（push）**は**右隣**のギルドへ資源を送り、**引き込み（pull）**は**左隣**から取る。

```
農民 ─→ 商人 ──→ 錬金術師 ─→ 騎士 ──→ 貴族 ──→ 修道士 ─→（農民へ戻る）
Farmer  Merchant  Alchemist   Knight    Noble     Monk
 物資     物資       発明       影響    王の印     ロザリオ
 goods    goods    inventions  マーカー            玉
                              influence king's    rosary
                               markers   seals     beads
```

- 環の折り返しについてルールが明示している。「修道士ギルドは農民ギルドの左隣であり、錬金術師ギルドは騎士ギルドの左隣である」
- 環に沿って実際に動くもの:
  - 農民 → 商人（Farmer → Merchant）: **物資5個**（押し出し）／商人は農民から**物資3個**を引き込む
  - 商人 → 錬金術師（Merchant → Alchemist）: **物資4個**（押し出し）／錬金術師は商人から**物資2個**を引き込む
  - 錬金術師（Alchemist）: 物資が**発明**（船・クルド樽）になる → クルドは騎士ギルドの**影響マーカー**を満たす
  - 騎士 → 貴族（Knight → Noble）: **影響マーカー1〜3個**を**王の印**に交換し貴族ギルドの巻物に置く／貴族は騎士から**影響マーカー2個**を引き込む
  - 貴族 → 修道士（Noble → Monk）: **王の印2個**を裏返して**ロザリオ玉**にする／修道士は城から**王の印1個**をロザリオへ引き込む
  - 修道士 → 農民（Monk → Farmer）: **玉2個**を提示し1個を**施し**として農民ギルドの鶏の上へ／農民は修道士から**玉2個**を引き込む
- 2つの金庫はボードの**対角**に位置する。**農民の財布**（farmer's purse／農民ギルド）と**教会金庫**（church coffer／修道士ギルド）。あらゆる支払いにおける弟子の分は、常にこのいずれか（「チャリティー」= charity）へ送られる。
- **押し出しは4/5/6 vp**（達成量に応じて増加）、**引き込みは3 vp ＋ 王命状2枚引いて1枚保持**。

## A7. 拠点の発展系列

```
   砦    ──木材──▶   農場   ──鉄──▶    町   ─王の印─▶      フューダム
Outpost     wood      Farm     iron     Town   king's seal    Feudum
    │                  │                 │                      │
   探索               収穫              徴税        家臣化（+3★）と軍役の義務
 explore            harvest             tax       vassalage & military service
 （王命状）         （物資）        （シリング）
```

- 拠点を改善できるのは、その拠点の**支配者**のみ。
- 改善ごとに、対応する地域の山から**地域タイル**1枚と、**地域タイル表**に応じた vp を得る（表の値はボード上に印刷。ルールブック本文には*町 × 時代I = 3 vp* のみ記載）。
- 農場 → 町の改善では、**その農場上の物資すべてを捨てる**。
- 征服された**フューダムは砦に戻る**（完全に消滅はしない）。
- 攻撃できるのは**ポーンとフューダムのみ**。砦・農場・町は**決して**標的にできない。
- 逆に、**影響マーカーで支配を奪えるのは砦・農場・町のみ**。フューダムの支配は3個目のマーカーでも「金は影響力」でも動かない（農奴にはなれる）。影響と征服は対象がちょうど逆になる。

## A8. 3つの並行する地位システム

この3つは別物であり混同しやすい。**訳語をはっきり分ける**必要がある。

**1. 拠点での役割**（影響マーカーで決まる。1拠点あたり最大3マーカー／2プレイヤー）

| 役割 | 条件 | 効果 |
| --- | --- | --- |
| **支配者**（ruler） | 最初のマーカーを拠点ディスクの**上**に置く | その拠点で改善・収穫・徴税・探索が可能。ギルド地位と活動地域に数える。農奴が資源を回収する際に1つ受け取る |
| **農奴**（serf） | 2人目（別プレイヤー）のマーカーを拠点ディスクの**横**に置く | その拠点に**地形を整備**できる。フューダムへの攻撃時に**反乱農奴**になれる |
| **臣民**（subject） | 支配者自身の2つ目のマーカーを拠点ディスクの**横**に置く | フューダムが攻撃されたとき**防御+1** |

**2. ギルド内の階級**（**地位星**で決まる。ポーン+1★、フューダム+3★＝いずれも**主要**条件／関連する支配拠点+1★＝**副次**条件、主要条件が必要）

関連する拠点の種類は各ギルド盤面の★凡例（3つ目のアイコン）で指定されています。**砦**＝修道士・錬金術師／**農場**＝農民・騎士／**町**＝商人・貴族。砦・農場・町のディスクにギルドアイコンはなく、アイコンがあるのは**フューダムだけ**です。

| 階級 | トラック上の位置 | 使える機能 | 各時代の始まりの vp |
| --- | --- | --- | --- |
| **ギルドマスター**（guild master） | 最も右 | **押し出し** | 5 vp |
| **職人**（journeyman） | 2番目 | **引き込み** | 3 vp |
| **弟子**（apprentice） | 3番目（4人以上のみ） | なし | 1 vp |

**3. 家臣関係**（フューダムの支配で決まる）

| 状態 | 帰結 |
| --- | --- |
| **家臣**（vassal、フューダムを1つ以上支配） | 関連ギルドで+3★。**軍役**の義務を負う。**不忠**により −3/−4/−5 vp（累積）を時代 II・IV・V の始まりに失う恐れ |
| **非家臣** | 減点なし。将来を見越して軍役トラックに征服実績を先に積んでおくことは可能 |

## A9. 各資源の用途

| 資源 | 用途（リファレンスカードの要約が**太字**） |
| --- | --- |
| **硝石**（saltpeter） | **追加アクション**（5枚目のカード）、**攻撃+1**（騎士がいれば無制限）、**デジャヴ** |
| **硫黄**（sulfur） | **連続アクション**（カード2枚連続。個人供給のものだけ）、**ポーンの扶養**（ワイン樽から。2ラウンド持続、最初のラウンドは攻撃・防御が0）、**宴**（樽から）。ゲーム終了時の同点処理にも使う |
| **鉄**（iron） | 農場 → 町の**改善**、**鋤と剣** |
| **木材**（wood） | 砦 → 農場の**改善**、**地形の整備** |
| **食料**（food） | **ポーンの扶養**、**王の免責**、ポーンを盤上に移住させる費用 |
| **地域タイル**（region tile） | **好きな物資として使える**（ワイルド）、または**地形**として配置 |
| **シリング**（shilling） | 渡し船の料金（2シリング）、ギルドでのあらゆる取引、ゲーム終了時に3シリング＝1 vp |

## A11. 基本ゲームと上級ゲーム

- セットアップの最後にこうある。「これで基本ゲームまたは上級ゲームを始められます」
- **上級ゲームの内容** = (a) 11枚のアクションカード下部の**特殊能力**（special ability）、(b) **代官**（Reeves）、(c) **獣を従える／モンスター**（Tame the Beast / monster）。すべてルールブック中の**巻物型の枠**に印刷されている。
- 特殊能力は通常アクション（regular action）を**強化するか置き換える**（enhance or replace）。カードによっては「いずれか一方」記号があり、**両方は行えない**。「地形の整備」（"Tend Landscape"）と「民を飢えさせる」（"Starve the People"）は明示的に「通常アクションの代わりにプレイする」（*Play this instead of the regular action.*）と書かれている。

## A12. 定型表現の訳し方（最重要）

以下はルールブック全体で繰り返される定型句。**1つの定型句に1つの訳を固定することが、一貫した日本語ルールブックへの最大の近道**です。

| # | 英語の定型句 | **確定訳** | 備考 |
| --- | --- | --- | --- |
| 1 | turn in *(a good)* to the haversack | **（物資を）麻袋に支払う** | 「turn in」は常に「支払う」。「返す」「捨てる」と訳し分けない |
| 2 | at the dawn of each epoch | **各時代の始まりに** | 「夜明け」とは訳さない（ステップ4の瞬間を指す機械的な語） |

| 20 | surpass (not tie) | **上回る（同数では不可）** | — |
| 21 | A tie is a failed action. | **同値の場合、アクションは失敗です。** | — |
| 22 | randomly draw / randomly select | **無作為に引く／無作為に選ぶ** | — |
| 23 | secretly | **秘密に** | — |
| 24 | in turn order / clockwise | **手番順に／時計回りに** | — |
