# 1. アクションカード（11種）

全員が同じ11枚を持ちます。毎ラウンド、そこから**4枚**（追加アクション使用時は5枚）を秘密に選び、手番順に1枚ずつ公開して解決します。カードは毎ラウンド全部手元に戻ります。

各カードは**上部＝通常アクション**、**下部＝特殊能力（上級ゲーム）**の二段構成です。特殊能力は通常アクションを強化するか、置き換えます。

![カードの見方（収穫アクション）。① ギルドコスト ② アクション名 ③ 通常アクションの効果 ④ 上級ゲームの特殊能力 ⑤ 各国語のアクション名|wide](figures/card-anatomy.jpg)

① 左上の紋章の数字は、このアクションでギルドに入るとき必要な**ギルドコスト**。② 上部の帯がアクション名。③ 上半分が**通常アクション**の効果。④ 下半分の絵の中に小さく描かれた記号が**上級ゲームの特殊能力**。⑤ 最下部はドイツ語・フランス語のアクション名。

## 各カードの詳細

### 1. 移住アクション *(p. 8)*

![移住アクションのカード|small](figures/card-migrate.jpg)

| | |
| --- | --- |
| **やること** | 自分のポーン1つを盤に出すか、盤から個人供給へ戻す |
| **費用** | 出すとき食料1個を麻袋に支払う。戻すときは無料 |
| **置く場所** | 自分のポーンか影響マーカーがある拠点の横。どちらもなければピンクの丸で囲まれた6つの開始拠点 |
| **向き** | 6面のうち1つの職能（農民・錬金術師・商人・騎士・貴族・修道士）を上に向ける。その職能のギルドに +1★ |
| **注意** | 盤上のポーンは毎ラウンド扶養が必要（→ 9章） |

> **「遠い親戚」（上級）** — 錬金術師のポーンが既に盤上にあれば、新しいポーンを**6つの開始拠点のいずれか**へ出せます（自分のポーンや影響マーカーがなくても可）。

### 2. 移動アクション *(p. 8)*

![移動アクションのカード|small](figures/card-move.jpg)

| | |
| --- | --- |
| **移動力** | 盤上の自分のポーンの数。複数のポーンに分配できる |
| **経路** | 道、または対応する乗り物を配置したルート |
| **掠め取り** | 移動の最後に、動かしたポーンの隣の拠点から資源1つを取れる。自分が支配する農場と、自分の農奴が整備する地形からは不可。移動1回につき1つまで |
| **乗り物** | 配置はアクション不要。一度置いた乗り物は盤から離れない |

### 3. 影響アクション *(p. 9)*

![影響アクションのカード|small](figures/card-influence.jpg)

| | |
| --- | --- |
| **やること** | 自分のポーンがいる**各**拠点に、影響マーカーを1個ずつ置く |
| **効率** | ポーンが3つの別々の拠点にいれば、一度に3個置ける |
| **上限** | 1拠点あたり3個まで、2プレイヤーまで。自分の石は最大2個 |

### 8. 征服アクション *(p. 13)*

![征服アクションのカード|small](figures/card-conquer.jpg)

| | |
| --- | --- |
| **対象** | 自分のポーンと同じ拠点にいる、**他家のポーンかフューダム**のみ。砦・農場・町は**決して**攻撃できない。逆に、**フューダムを奪う手段は征服だけ**（影響では奪えない） |
| **判定** | 攻撃値が防御値を**上回れば**成功。同値は失敗（→ 10章） |
| **得点** | ポーン 2 vp／フューダム 4 vp。軍役トラックにプレイヤーディスクを1枚置ける |

| **結果（フューダム）** | 砦に戻る。影響マーカーは持ち主に返るが、攻撃側の**反乱農奴**がいればその農奴が砦の支配者になる。物資と地形は残る |
| **制限** | **そのラウンドの最後のアクションにできない** |

> **「民を飢えさせる」（上級）** — 貴族のポーンが隣接する拠点で、他家の**臣民か農奴を1つ除去**します。得点は入りませんが軍役は進められます。**征服の代わり**に行います。成功すると農民ギルドの鶏の上の**施しがすべて除去**されます。

### 11. ギルドアクション *(p. 15)*

![ギルドアクションのカード|small](figures/card-guild.jpg)

1つのギルドを選び、次の3つの機能から**1つ**を行います。

| 機能 | 誰が | 内容 |
| --- | --- | --- |
| **取引** | どのプレイヤーでも | そのギルドの品を買う・交換する |
| **引き込み** | 職人（2番手） | **左隣**のギルドから資源を取る。3 vp ＋王命状2枚引いて1枚保持 |
| **押し出し** | ギルドマスター（首位） | **右隣**のギルドへ資源を送る。4/5/6 vp |

**支払いの順序** — 取引でシリングを払うときは、3シリングごとに**ギルドマスターへ1／職人へ1／チャリティー（反対側の農民の財布か教会金庫）へ1**。不在の会員の分は共通供給へ戻します（チャリティーの分は除く）。自分のギルドで買う場合も、**総額を手持ちで用意する**必要があります。

> **「宴」（上級）** — ワイン樽の硫黄1を支払い、自分のポーンが隣にいるポーンかフューダムの持ち主を選びます。その者の押し出しか引き込みを代行し、**その者の通常点 +3 vp** を得ます。金庫の分配が起きたら、その者の取り分も受け取ります。

# 2. 6つのギルド

6つのギルドは環状に並び、**押し出しは右隣へ、引き込みは左隣から**。修道士の左は貴族、農民の左は修道士です。

各ギルドの下の値は、そのギルドのギルドマスターが**押し出し**で右隣へ送るものです。

**席の決まり方** — 地位星★の数で決まります。ポーン +1★、フューダム +3★（ここまでが**主要条件**）、関連する支配拠点 +1★（**副次条件**。主要条件がなければ数えません）。★を得たら影響マーカーをギルドトラックに置くことが**義務**で、ギルドの石は回収できません。

**どの拠点がどのギルドの★になるか** — 各ギルド盤面の右上（★凡例の3つ目）に印刷されています。砦・農場・町のディスクにギルドアイコンはなく、**アイコンがあるのはフューダムだけ**です。

| 拠点 | ★になるギルド |
| --- | --- |
| **砦**（紫の円・城塔） | 修道士 ／ 錬金術師 |
| **農場**（黄緑の円・畝） | 農民 ／ 騎士 |
| **町**（黄色の円・家並み） | 商人 ／ 貴族 |
| **フューダム** | ディスクに描かれたアイコンのギルド1つ（+3★・主要） |

拠点1つは常に2つのギルドの★になります。逆に、**改善で種類が変われば★の行き先も変わります**。農場→町なら農民・騎士 −1★／商人・貴族 +1★。移った先に主要条件がなければ、★は減るだけです。

| 席 | 順位 | 使える機能 | 各時代の始まりの得点 |
| --- | --- | --- | --- |
| ギルドマスター | 1位 | 押し出し | 5 vp |
| 職人 | 2位 | 引き込み | 3 vp |
| 弟子 | 3位（4人以上のみ） | なし | 1 vp |

同数では席を奪えません（**上回る**必要があります）。

# 3. 王命状カード（16枚）

引いて手元に持つカードです。**手札は3枚まで**。不要なカードはいつでも山札の一番下に戻せます。

| 種類 | 枚数 | 使い方 |
| --- | --- | --- |
| **指令** | 8枚 | いつでもプレイして捨てられる。資源や攻撃力を得る。四角で囲まれた物資の支払いか、ギルド地位が条件のものがある |
| **特許状** | 8枚 | ゲーム終了時に得点する。**王の印を載せなければ 0 点** |

**入手経路** — 探索アクション／ギルドの引き込み／大巡礼トラックのカードアイコンのマス。

# 4. 拠点と役割

## 拠点の4種類

![拠点ディスク4種。砦・農場・町・フューダムの表面|wide](figures/locations-4.jpg)

| 拠点 | 改善費用 | 解禁されるアクション | ★になるギルド（副次 +1★） | 大帝国（終了時） | 影響で奪われる | 攻撃 |
| --- | --- | --- | --- | --- | --- | --- |
| **砦** | — | 探索 | 修道士・錬金術師 | 1 vp | 奪われる | されない |
| **農場** | :木材:1（砦から） | 収穫 | 農民・騎士 | 1 vp | 奪われる | されない |
| **町** | :鉄:1（農場から） | 徴税 | 商人・貴族 | 1 vp | 奪われる | されない |
| **フューダム** | 王の印1（町から） | 収穫・徴税・探索の増加分として数える | ディスクのアイコンのギルド1つ（**+3★**・主要） | 3 vp | **奪われない** | **される** |

- 改善できるのは、その拠点の**支配者**だけです。
- フューダムを支配すると**家臣**となり、**軍役**の義務を負います（→ 9章）。
- **影響と征服は、対象がちょうど逆です。** 砦・農場・町は影響マーカーで支配を奪えますが攻撃されません。フューダムは影響では奪えませんが、**征服だけが**取り上げる手段です。
- 征服されたフューダムは**砦に戻ります**。
- 終了時、同じ種類を3つ支配していると **+3 vp**（フューダムはワイルドとして数えます）。

## 拠点での役割

![支配者・農奴・臣民の影響マーカーの置き方|wide](figures/roles-placement.jpg)

| 役割 | 置き方 | できること |
| --- | --- | --- |
| **支配者** | 最初の影響マーカーを拠点ディスクの**上**に | 改善・収穫・徴税・探索。★・活動地域・大帝国に数える。農奴が資源を回収したとき1つ受け取る |

# 6. 地形（4種）

地形は**農奴**が「地形の整備」で拠点の横に敷きます。1拠点に1つまで、置き換え不可。

![地形4種。果樹園・弓術場・銀鉱山・硫黄鉱山|wide](figures/landscapes-4.jpg)

| 地形 | 産出 | 産出物の使い道 |
| --- | --- | --- |
| **果樹園** | :食料: | 扶養、移住 |
| **弓術場** | 弓術標的 | 回収時に影響マーカーと交換 |
| **銀鉱山** | シリング | 取引、終了時得点 |
| **硫黄鉱山** | :硫黄: | ワイン、連続アクション、宴 |

| 場面 | 起きること |
| --- | --- |
| 敷いた瞬間 | **2 vp** |
| 各時代の始まり | 資源が3つ足される。**空なら 2 vp、資源が1つ以上あれば 4 vp** |
| 回収するとき | 蓄積した資源をすべて取り、**その拠点の支配者に1つ渡す** |
| 放置するとき | 決算の点は高いままだが、他家に**掠め取られる**危険がある |

地形のある地域は、農奴でも**活動地域**として数えます。

| **ベヒモス** | 道と飛行機械ルート | 自分の影響マーカーかポーンがある拠点 |
| **シーサーペント** | 帆船ルートと潜水艇ルート | 海か川に接する**港** |

**共通の性質**

- 移動力に加算される。**掠め取り・征服・武器の使用**ができる
- 敵のポーンを**足止め**する（盤外への移住か、モンスターの撃破以外で離脱できない）
- 防御は **+1** のみ
- 拠点への影響、宴、乗り物の使用は**できない**
- **扶養は不要**（人を食べるため）
- 撃破されると騎士ギルドへ戻り、持ち主は影響マーカーを回収する

## 時代の進行

| 時代 | 発生条件 |
| --- | --- |
| II | 時代IIのタイルが**4枚**見えている |
| III | 時代IIIのタイルが**3枚**見えている |
| IV | 時代IVのタイルが**2枚**見えている |
| V | 時代Vのスペースが**1つ**見えている（→ゲーム終了） |

**時代を進める時計は、経過ラウンド数ではなく地域タイルの残り枚数です。** 山が減って下のタイルが見えることが、上の条件を満たします。

タイルが減る経路は2つあります。

- **進行ダイス** — 毎ラウンド必ず1枚（→「ラウンドの5ステップ」の③）
- **改善** — 1回につき1枚。改善したプレイヤーが報酬として引き取る

前者だけなら1ラウンド1枚ですが、**改善が挟まるたびに時計が余分に進みます**。「5つの時代で通常7〜10ラウンド」の幅は、ここから出ています。卓が土地の開発を競うほど時代は早く巡り、終幕も前倒しになります。

つまり**改善は、報酬と引き換えに自分で時計を回す行為**です。決算の回数を増やしたいのか減らしたいのかで、同じ改善の価値が変わります（→『追放者の手引き』「幕は他人が引く」）。

## 時代の始まりの処理（この順に行う）

| # | 処理 | 対象の時代 |
| --- | --- | --- |
| 1 | **得点** ギルド地位 1/3/5、地形 2/4、活動地域 1/3/5/7/9/11 | 全時代 |
| 2 | **不忠の減点** −3／−4／−5（累積） | **II・IV・V のみ** |
| 3 | **地形の補充** 各地形に資源3つ | 全時代 |
| 4 | **地図の補充** 陽光の方位（S/E/W）の拠点に物資1個 | **II・III・IV のみ** |
| 5 | **ギルドの補充** 6ギルドをセットアップの状態まで | **III のみ** |

## ラウンドの5ステップ

| # | ステップ | 内容 |
| --- | --- | --- |
| 1 | アクションの実行 | 11枚から4枚を秘密に選び、手番順に1枚ずつ |
| 2 | ポーンの扶養 | ポーン1つにつき食料1個、またはワイン樽の硫黄1個 |
| 3 | 進行ダイスを振る | 出た地域の地域タイルを1枚除去 |
| 4 | 時代マーカーの進行と得点計算 | 発生した場合のみ |
| 5 | ラウンド終了／ゲーム終了 | 開始プレイヤーマーカーを時計回りに |

**ワイン** — 樽の硫黄をポーンの上に載せると**2ラウンド**保ちます。ただし**載せた最初のラウンドは攻撃も防御も0**になります。樽は3個まで。

# 10. 戦闘の修正値

攻撃値が防御値を**上回れば**成功。**同値は失敗**です。

| 要素 | 攻撃 | 防御 |
| --- | --- | --- |
| キャラクターポーン | +1 | +2 |
| モンスター | +1 | +1 |
| ワインを載せたポーン（載せた最初のラウンド） | 0 | 0 |
| 硝石 | +1（**騎士が参加していれば何個でも**） | — |
| 武器（弓・剣。王命状の指令） | +1 / +2 | — |
| フューダム | — | +2 |
| 臣民 | — | +1 |
| 反乱農奴（攻撃側） | +1 | — |
| 防御アクション（手番外で公開） | — | +1 |

- 複数のポーンで攻撃・防御できますが、標的は**1つ**だけです。
- 第三者のポーンや農奴は戦闘に**加わりません**。
- 硝石と武器は、相手が防御アクションを公開した**後でも**足せます。
