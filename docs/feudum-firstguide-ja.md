# Feudum はじめてガイド

*— プレイ前に読む全体像*

> - **対象** — Feudum をまだ一度もプレイしていない方。経験者と一緒に遊ぶ前提です。
> - **目的** — 読み終わったら、経験者の隣に座って第1ラウンドを始められること。それだけを狙います。
> - **読む時間** — 10分ほど。プレイ中は裏表紙の早見だけ見返してください。
>
> このガイドに**具体的な点数や細かい手順は出てきません**。それらは同卓の経験者がその場で教えてくれます。詳しいルールは『Feudum 日本語ルールブック』、勝ち方は『追放者の手引き』を参照してください。

---

## 1. これはどういうゲームか

要点は3つです。

1. あなたは**追放された貴族**です。異国の地に流れ着き、名誉を取り戻そうとしています。
2. 名誉は**崇敬点（vp）**という点数で数えます。以下、単に「点」と呼びます。
3. **5つの時代**を通じて、いちばん多く点を稼いだ人が勝ちます。

---

## 2. 点が入る4つの方向

:::grid2
#### ① 土地を支配する
拠点に影響マーカーを置いて**支配者**になる。**いちばん大事**。
+++
#### ② ギルドで出世する
6つのギルドの席に座る。①をやると自然に進む。
+++
#### ③ いろんな地域に広がる
旗を立てた地域の数で点。増えるほど1つの価値が上がる。
+++
#### ④ 早く整える
②と③は**時代が変わるたびに繰り返し**入る。早い者ほど得。
:::

点の入り方は多いですが、**大きく4つの方向**にまとめられます。数字は不要で、「どちらに動けば点になるか」だけ分かれば十分です。

### ① 土地を支配する

![拠点ディスクの上に影響マーカーを置いた状態＝支配者|half](figures/beginner-ruler.jpg)

盤の上には、砦・農場・町といった**拠点**が並んでいます。そこに自分の**影響マーカー**（自分の色の六角柱の駒）を置くと、その土地の**支配者**になれます。

**これがいちばん大事です。** 土地を支配すると、②と③も同時に進みます。

### ② ギルドで出世する

盤の周りには**6つのギルド**（農民・商人・錬金術師・騎士・貴族・修道士）があります。それぞれに席があり、上位に座ると点が入ります。

席の順位は「そのギルドに関係する駒や土地をどれだけ持っているか」で決まります。つまり①をやると、自然に②も進みます。

### ③ いろんな地域に広がる

盤は**6つの地域**（海・島・森・砂漠・荒地・山）に分かれています。**旗を立てた地域の数**が多いほど点が入ります。しかも、地域が増えるほど1地域あたりの価値が上がります。

一か所に固まらず、少しずつ広げるのが得です。

### ④ 時代の変わり目に決算がある

②と③は、**時代が変わるたびに繰り返し点が入ります**。**早く整えた人ほど、同じ状態から何度も点をもらえます**。終盤に慌てて整えても、もらえるのは一度きりです。

> **この章のまとめ**
> 点の出どころは「土地を支配する／ギルドで出世する／地域に広がる／それを早く整える」の4方向。
> そして**この4つはつながっています**。土地を1つ支配するだけで、①②③が同時に進みます。
> **迷ったら土地を取る。** これがいちばん確実です。

## 3. 毎ラウンドやること

ルールは複雑に見えますが、**実際にやることは1つ**です。

> **全員が同じ11枚のカードを持っています。毎ラウンド、そこから4枚を選び、順番に1枚ずつ出します。**

この1点が分かれば、プレイは回ります。

### 覚えなくていいこと

![アクションカード11枚を並べたところ。中身は覚えなくてよい|wide](figures/cards-11.jpg)

**11枚のカードの中身を覚える必要はありません。** カードは絵と記号だけで書かれています。「これは何ができるカードですか」と聞けば、経験者が教えてくれます。

### 知っておくこと

- カードは**毎ラウンド全部手元に戻ってきます**。使い切りではないので、出し惜しみは不要です。
- 4枚は**全員が同時に、伏せて選びます**。選び終わったら、手番順に1枚ずつ表にして解決していきます。
- 選んだ4枚は、そのラウンド中にすべて出します。

### 選び方のコツ

「今回のラウンドでやりたいこと」を**1つだけ**決めてください。そして、それに必要なカードを選びます。

たとえば「土地を1つ支配したい」なら、ポーンをその土地へ動かすカードと、影響マーカーを置くカードを選びます。4枚すべてに意味を持たせる必要はありません。

## 4. 1ラウンドの流れ

:::round
**カードを4枚選ぶ**
全員同時・伏せて
+++
**1枚ずつ出す**
手番順に解決
+++
**餌をやる**
ポーン1つに食料1つ
+++
**時代の判定**
ダイスを振る。変われば決算
+++
**次のラウンドへ**
カードは全部戻る
:::

<p class="round-note"><b>①②</b> が自分で考えるところ。③〜⑤は決まった手順です。</p>

![セットアップが終わった卓の全景|wide](figures/setup-done.jpg)

ゲーム全体は5つの時代・おおよそ7〜10ラウンドです。ラウンド数と時代の数は一致せず、**何ラウンドか進むと時代が1つ切り替わります**。

## 5. 最初の数手

> **最初は「影響」と「移住」を中心に選んでください。**

- **影響**（インフルエンス）— 自分のポーンがいる拠点に、影響マーカーを置きます。これで土地の支配者になります。
- **移住** — 自分のポーンを盤に増やします（食料を1つ払います）。ポーンが増えると、できることが増えます。

この2つが**土台**になります。第2章の①②③がまとめて進むためです。

### 効率のよい出し方

**「移動」でポーンを別々の場所に散らしてから「影響」を出す**と、一度に複数の土地へ影響マーカーを置けます。

### 最初はやらなくていいこと

- **フューダム**（領主から授かる領地のこと。拠点の最上位）を建てる
- 他のプレイヤーを**攻撃する**
- 遠くの海へ**船を出す**

どれも強い手ですが準備が要ります。初回は手を出さないほうが良い順位になります。

### 序盤の目標

**拠点を2つ支配して、2つのギルドに影響マーカーを乗せる。** これが序盤の目標です。

## 6. つまずきやすい3つ

先に知っておけば避けられます。

### ① 餌やりを忘れると駒が消える

ラウンドの終わりに、**盤上のポーン1つにつき食料が1つ**必要です（ワインでも代用できます）。払えないポーンは手元に戻ります。そのポーンがギルドの地位を支えていた場合は、**席まで失います**。

**ポーンを増やす前に、食料の残りを確認してください。**

### ② 出世すると手元の石が減る

ギルドで地位を得ると、**影響マーカーがギルドへ強制的に移され、戻ってきません**。気づくと手元が空になり、土地を取りたくても石がない状態になります。

**出世すると石が減る**、と覚えておきます。減ってきたら、経験者に「石を補充する方法はありますか」と聞きます。

### ③ フューダムには義務がつく

フューダム（領地）を持つと大きな力が手に入りますが、王への**軍役**という義務を負います。果たさないと**点が引かれます**。このゲームで点が減るのはここだけです。

**初回は建てないのが無難です。** 勧められたら「軍役はどうやって果たすんですか」と聞いてください。

## 7. 用語ミニ対応

経験者が口にする言葉と、その意味です。

| 経験者が言う言葉 | 意味 |
| --- | --- |
| インフルエンス | **影響**。土地に影響マーカーを置くアクション |
| トレード | **取引**。ギルドでの買い物。誰でもできる |
| プル（pull） | **引き込み**。ギルドの2番手が、隣のギルドから資源を取る |
| プッシュ（push） | **押し出し**。ギルドの首位が、隣のギルドへ資源を送る |
| ギルドマスター | ギルドの**首位**。2番手は**職人**、3番手は**弟子** |
| エポック | **時代**。全部で5つ。変わり目に決算があり、点が入る |
| フューダム | **領地**。拠点の最上位。強いが軍役の義務がつく |
| 勅令／ロイヤルリット | **王命状**。引いて手札にするカード |
| リーブ | **代官**。ギルドに置いて点を上乗せする自分のディスク |
| エピックボヤージュ | **大巡礼**。山頂の修道院を目指す、盤の端のトラック |
| ポーン | 自分の**6面ダイス型の駒**。上を向いた面の職業として働く |
| 扶養（ふよう） | **餌やり**のこと。ルールブックではこう書かれています |

<p class="round-note"><b>①②</b> が考えるところ。③〜⑤は手順。</p>

### 初手はこの2つ

- **影響** — 土地に影響マーカーを置いて支配者になる
- **移住** — ポーンを盤に増やす（食料を1つ払う）

コツ: **移動で散らしてから、影響を出す。**

### 迷ったら

**土地を取る。** 土地の支配は、点の4方向のうち3つに同時に効きます。

### 最初はやらないこと

フューダムを建てる／攻撃する／遠くへ船を出す

### 忘れずに

ラウンドの終わりに、**ポーン1つにつき食料1つ**。

### 困ったら、この3つを聞く

1. 「このカードは何ができますか？」
2. 「いま私がやると点になることは何ですか？」
3. 「この手をやると、後で困ることはありますか？」
