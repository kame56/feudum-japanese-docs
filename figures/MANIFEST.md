# 図版マニフェスト

このディレクトリに入れる画像の一覧と仕様です。**用意していただきたい画像**と、**すでにPDFから切り出してある画像**を分けて記載しています。

## 仕組み

各ドキュメントの Markdown には、次の形式で**画像スロット**が埋め込まれています。

```markdown
![キャプション|サイズ](figures/card-migrate.jpg)
```

- ビルド時、`figures/` に同名のファイルが**あれば画像として埋め込まれ**、**なければ点線の枠（画像スロット）**が描かれます。
- したがって、画像を用意した順に差し替えていけます。原稿の修正は不要です。
- `|サイズ` は版面に対する幅の指定です。

| サイズ指定 | 版面に対する幅 | 想定用途 |
| --- | --- | --- |
| `full` | 100% | セットアップ全景、トラック全体などの横長 |
| `wide` | 68% | ボード全体、一覧写真 |
| `half` | 52% | ギルド1つ、部分図 |
| `small` | 30% | カード1枚、アイコン |

## 画像の共通仕様

| 項目 | 推奨 |
| --- | --- |
| 形式 | JPEG（`.jpg`）。透過が必要なものだけPNG |
| 幅 | `full`/`wide` は長辺 **1600px以上**、`half` は **1000px以上**、`small` は **600px以上** |
| 色 | 実物の色味に近ければ加工不要。斜めからの撮影は避け、**真上から** |
| 背景 | 白または無地。盤面の一部を撮る場合は周囲を含めすぎない |
| 文字 | カードやボードの英語表記はそのままで構いません（本文とキャプションで意味を補っています） |
| 容量 | 1枚 500KB 以内が目安（HTMLに base64 で埋め込むため） |

# 特に撮っていただきたいもの（判読できていない情報）

原書PDFの画像が低解像度のため、以下の**数値が確認できていません**。実物のボードを撮影いただければ、各ドキュメントの該当箇所を数値入りに更新できます。

| 撮影対象 | 何が知りたいか | 影響する箇所 |
| --- | --- | --- |
| **軍役トラック** | 投石機スペースに印字された数値 | ルールブック §9.4、リファレンス 9章 |
| **ギルドの拠点アイコン** | どの砦／農場／町がどのギルドに対応するか | リファレンス 2章、攻略冊子 四章 |
| **vp（崇敬点）の記号** | 正確な図柄 | リファレンス 11章 |

# 画像の出どころ

3系統あります。差し替えるときは**同じファイル名で上書き**すれば、どの系統でも反映されます。

| 系統 | 素材の置き場 | 生成スクリプト | 品質 |
| --- | --- | --- | --- |
| 原書PDFの埋め込み画像 | `icons/`（[CATALOG](icons/CATALOG.md) / [一覧](icons/index.html)） | `scripts/compose_figures.py` | 元が75 ppi。細部は判読不可 |
| Dized の公式アートワーク | `nice/`（[CATALOG](nice/CATALOG.md)） | `scripts/place_nice_figures.py` | 記号・数字まで読める |
| ブログ記事の実物写真 | `web/` | 手動配置 | 実物。角度と照明はまちまち |
